Static visualization of the current Lua virtual-lines viewer logic. Each sample is treated as one coalesced hunk, then old/new lines are paired by position and token-LCS focus spans are drawn inside paired lines.

Algorithm Modeled

This page mirrors the current intraline logic in lua/minuet/duet/preview.lua.

  • Whitespace runs are tokens.
  • ASCII word and underscore runs are tokens.
  • Punctuation is one token per character.
  • LCS matches are anchors.
  • Unmatched token ranges become focus spans.
